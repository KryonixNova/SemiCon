# RGB Dataset Generator — Sample Output

Generated by `generate_dataset.py` with RGB output enabled (3-channel PNG).

## What changed

`generate_dataset.py` now saves reference and search images as 3-channel RGB PNGs
instead of single-channel grayscale. The pixel values are identical across all three
channels — the underlying SEM data is physically grayscale — but the file format is
now compatible with tools and pipelines that expect color images.

## Output structure

```
output_rgb_test/
  manifest.csv          # ground-truth locations + generation metadata
  reference/            # high-res Reference crops (100x100 px, 1 nm/px)
    00000.png
    00001.png
    00002.png
  search/               # wide-area Search images (1000x1000 px, 10 nm/px)
    00000.png
    00001.png
    00002.png
```

## Reproduce

```bash
python generate_dataset.py --num-samples 3 --output-dir ./output_rgb_test
```

## Verify RGB

```python
import cv2
img = cv2.imread("output_rgb_test/reference/00000.png")
print(img.shape)  # (100, 100, 3)
print((img[:,:,0] == img[:,:,1]).all())  # True — channels are identical
```

## Full options

```
--num-samples N           number of pairs to generate (default: 30)
--split {train,val,test}  canvas-disjoint seed range to draw from
--seed INT                starting canvas seed
--output-dir PATH         destination directory
--imaging-noise-profile {normal,harsh}
--geometric-profile {normal,drift}
--crops-per-canvas N      reference crops per canvas before moving on
```
